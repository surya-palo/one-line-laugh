One funny line, written by `main.py` (Python stdlib only) to `/output/entry.txt`.

## The line

> I set my alarm for 6 a.m. to start the day early, then spent the first hour lying in bed resenting the idiot who set it.

120 characters, one sentence. The joke: the alarm's enemy isn't the morning — it's yesterday-you, the person who set it. An everyday truth (we all set alarms we immediately resent), a surprise at the end (the "idiot" is me), and no wasted words.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic: two runs produce byte-identical output.
